Find “your” community in a network you don’t fully see

Real social platforms mix public connections with private ones (visible only to some users). We search for a tightly connected group around a person using both connections and shared attributes.

Background & motivation

What is community search?
  • Goal: given a query vertex, find a cohesive subgraph containing the query.
  • Why useful: discover potential collaboration groups; identify social communities in networks.
What are public-private graphs?

Private relationships (examples)

  • Weibo: secretly follow
  • Xiaohongshu, TikTok: hide followers and fans
  • Facebook: hide friend list

Public-private graphs

  • Global public graph shared by all users
  • User-specific private edges and attributes
  • Personalized graph view for each user
  • Public part: a global graph shared by all users.
  • Private part: user-specific private edges and attributes.
  • Result: each user has a personalized graph view.
So what is the motivation?
  • Problem: Find a community containing a query user under that user’s personalized view.
  • Why hard: structure and attributes may disagree; every user’s private view is different; building an index per user is expensive.
  • Goal: efficient private-information integration + efficient community search.
